**Course:** Backend Development Lab

## 1. Aim

To design a web page that demonstrates commonly used HTML5 elements, including semantic structure, text formatting, lists, tables, forms, embedded graphics and interactive elements.

## 2. Objectives

- Understand the basic structure of an HTML5 document.
- Use semantic elements such as `header`, `nav`, `main`, `section`, `article`, `aside` and `footer`.
- Create lists and accessible tables.
- Use form controls and built-in validation.
- Demonstrate SVG, progress, meter, details and output elements.

## 3. Tools Required

- Visual Studio Code or another text editor
- A modern web browser
- HTML5, CSS3 and basic JavaScript

## 4. Theory

HTML (HyperText Markup Language) defines the structure and meaning of web content. HTML5 provides semantic elements that describe page regions, native form input types, multimedia support and interactive elements. Semantic markup improves maintainability and helps browsers and assistive technologies understand the document.

The experiment demonstrates:
- **Document structure:** `<!doctype html>`, `html`, `head`, `meta`, `title` and `body`.
- **Semantic layout:** `header`, `nav`, `main`, `section`, `article`, `aside` and `footer`.
- **Text and grouping:** headings, paragraphs, `strong`, `em`, `mark`, `blockquote`, lists and `details`.
- **Tabular information:** `table`, `caption`, `thead`, `tbody`, `tfoot`, `tr`, `th` and `td`.
- **Forms:** labels, inputs, select, textarea, datalist, fieldset and legend.
- **Other content:** inline SVG, progress, meter, time, output and noscript.

## 5. Procedure

1. Create an HTML file and declare the HTML5 doctype.
2. Add character encoding, viewport metadata and a meaningful title.
3. Divide the page into semantic sections.
4. Add text examples, lists and a timetable.
5. Create a form with labels and suitable input types.
6. Add an SVG illustration and native interactive elements.
7. Apply CSS for spacing, colour and responsive layout.
8. Open the file in a browser and test the form.

## 6. Output and Observation

The page displays the different HTML5 element groups. The form checks required fields and email format using browser validation. Its submit handler displays a demo confirmation without sending data to a server. The layout changes to one column on narrower screens.

## 7. Result

A web page demonstrating HTML5 semantic, text, table, form, graphic and interactive elements was created successfully.

## 8. Conclusion

This experiment provided practical experience with HTML5 structure and commonly used elements. Semantic elements make page sections easier to understand, while native form controls provide useful input behaviour and validation.
