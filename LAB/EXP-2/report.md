## 4. Theory

CSS (Cascading Style Sheets) controls the presentation of HTML. It defines colours, typography, spacing, borders and layout. When multiple rules match an element, the browser resolves them through the cascade, specificity and source order.

**CSS methods:** Inline CSS is written in an element's `style` attribute. Internal CSS is written in a `style` element in the document head. External CSS is stored in a separate file and connected using `link`. External stylesheets are useful for keeping presentation reusable and separate from page structure.

**Selectors:** An element selector targets a tag, a class selector targets elements sharing a class, and an ID selector targets an element with a particular ID. Descendant selectors target nested elements. Pseudo-classes such as `:hover` respond to an element's state.

**Box model:** The content is surrounded by padding, border and margin. The `box-sizing: border-box` rule makes declared dimensions include padding and border.

**Layouts:** Flexbox is designed mainly for one-dimensional alignment. Grid manages rows and columns together. Media queries apply layout changes when viewport or user-preference conditions match.
