## 1. Aim

To build responsive web pages using Bootstrap and Tailwind CSS and understand their different approaches to styling and layout.

## 2. Objectives

- Use Bootstrap's grid, components and utility classes.
- Use Tailwind's utility-first classes and responsive variants.
- Compare breakpoints, spacing, typography and customization.
- Build a similar interface using both frameworks.

## 3. Tools and Environment

Visual Studio Code, a modern browser, HTML5, Bootstrap 5 and Tailwind CSS. Both framework pages use CDN links and therefore require an internet connection.

## 4. Theory

A CSS framework provides reusable conventions and tools for building user interfaces. Bootstrap provides a responsive grid and predefined components such as cards and buttons. Tailwind CSS uses utility classes that are combined directly in the markup to describe layout and appearance.

Bootstrap commonly uses a container, row and column structure. Tailwind expresses the same layout through utilities such as `grid`, `gap-4`, `sm:grid-cols-2` and `lg:grid-cols-4`.

## 5. Procedure

1. Create an overview page linking the two implementations.
2. Build the Bootstrap page using its CDN stylesheet and responsive grid classes.
3. Build the Tailwind page using its browser CDN and responsive utility classes.
4. Keep the content similar so the approaches can be compared.
5. Resize the browser to observe how the cards adapt.

## 6. Output and Observation

The Bootstrap page uses predefined component and grid classes. The Tailwind page uses utility classes directly on the elements. Both pages change their card layout as the viewport narrows.

## 7. Result

Responsive pages were created using Bootstrap and Tailwind CSS.

## 8. Conclusion

Both frameworks reduce the amount of custom CSS needed for common layouts. Bootstrap offers predefined components and conventions, while Tailwind offers fine-grained styling through utility classes.
