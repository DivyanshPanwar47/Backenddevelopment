CSS Grid

04

Media queries

Media queries adapt the composition when the screen becomes narrower.

02 / Responsive approach

Built around the content

The feature cards use CSS Grid. The navigation uses Flexbox and can wrap onto another line. The heading uses clamp() so its size scales within readable limits.

Viewport test

Resize the browser window or open this page on a phone. The layout moves from four columns to two and then one column.

Responsive layout enabled

03 / Observation

Readable at every width

Content remains in a logical order when the columns stack. No fixed page width is required, and the navigation wraps instead of overflowing.
