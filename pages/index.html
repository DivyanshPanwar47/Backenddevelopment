This repository contains Backend Development coursework, laboratory experiments, reports and practical projects completed as part of the B.Tech CSE programme at UPES. Running the Experiments

  • Experiments 1–4: open the relevant HTML file in a browser.
  • Experiment 5: open its HTML file and use the developer console, or run the scripts with Node.js.
  • Experiments 12 and 12B: install dependencies, configure environment variables and run the Node.js server.
  • Experiments 13A, 13B, 14 and 15: follow the setup instructions in each experiment README.
  • Keep real credentials in local environment files; do not commit database passwords or JWT secrets.

Technologies Used

Frontend: HTML5, CSS3, JavaScript, Bootstrap and Tailwind CSS.
Backend: Node.js, Express.js, EJS, Django and Python / Flask.
Databases: SQLite, MongoDB, Mongoose and PostgreSQL with JSONB.
Security and tooling: bcrypt, JWT, Git, GitHub, Docker and GitHub Actions.

Learning Outcomes

  • Build structured web pages with semantic HTML5 and responsive CSS.
  • Use JavaScript arrays, objects, functions and browser storage.
  • Develop HTTP routes and dynamic pages using Node.js, Express and EJS.
  • Manage sessions, cookies, authentication and protected CRUD endpoints.
  • Compare relational PostgreSQL queries with MongoDB documents and JSONB.
  • Build a Django Todo application with SQLite, Admin, templates and static files.
  • Organise practical work and document implementations using Git and GitHub.
